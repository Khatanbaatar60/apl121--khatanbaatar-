# Тестүүд — Таксины тариф

Тариф: суух 1000₮, 1 км 1500₮, хүлээлгийн 1 мин 200₮, шөнө +20%.
Нэг тест = програмыг нэг удаа ажиллуулах (3 аялал). Оролт бүрийг **зай, хүлээлэг (мин), шөнө (1/0)** дарааллаар бичсэн.

Томьёо: `үнэ = 1000 + зай × 1500 + мин × 200`, шөнө бол `үнэ × 1.2`.

| № | Төрөл | Оролт (аялал 1 / 2 / 3) | Хүлээгдэж буй | Flowgorithm гаралт | C гаралт |
|---|---|---|---|---|---|
| 1 | Энгийн тохиолдол | `5 3 0` / `4 0 1` / `7.5 10 0` | Үнэ: 9100, 8400, 14250. Эрэмбэ: 2 → 1 → 3 | | Үнэ: 9100, 8400, 14250. Эрэмбэ: 1. Аялал 2, 2. Аялал 1, 3. Аялал 3 ✅ |
| 2 | Бүгд шөнө | `1 0 1` / `2 0 1` / `3 5 1` | 2500×1.2 = 3000, 4000×1.2 = 4800, 6500×1.2 = 7800. Эрэмбэ: 1 → 2 → 3 | | Үнэ: 3000, 4800, 7800. Эрэмбэ: 1. Аялал 1, 2. Аялал 2, 3. Аялал 3 ✅ |
| 3 | Ижил үнэтэй аялал | `2 0 0` / `2 0 0` / `1 0 0` | 4000, 4000, 2500. Аялал 1, 2 хоёулаа 2-р байр | | 1. Аялал 3: 2500, 2. Аялал 1: 4000, 2. Аялал 2: 4000 ✅ |
| 4 | **Хилийн утга** | `0` → `1 0 0` / `10 0 0` / `1 0 1` | Зай = 0 нь хил: татгалзаж, дахин асууна. Хүлээлэг = 0 нь хил: зөвшөөрнө. Үнэ: 2500, 16000, 3000. Эрэмбэ: 1 → 3 → 2 | | "Буруу утга!" 1 удаа. Үнэ: 2500, 16000, 3000. Эрэмбэ: 1. Аялал 1, 2. Аялал 3, 3. Аялал 2 ✅ |
| 5 | **Буруу оролт** | `-5` → `3`, `-2` → `4`, `2` → `1` / `2 0 0` / `6 0 0` | Сөрөг зай, сөрөг минут, шөнө = 2 гурвуулаа татгалзагдана. (1000+4500+800)×1.2 = 7560, 4000, 10000. Эрэмбэ: 2 → 1 → 3 | | "Буруу утга!" 3 удаа. Үнэ: 7560, 4000, 10000. Эрэмбэ: 1. Аялал 2, 2. Аялал 1, 3. Аялал 3 ✅ |

**Нэмэлт шалгалт — 1–10 км-ийн хүснэгт** (бүх тестэд ижил):
1 км → 2500 / 3000, 5 км → 8500 / 10200, 10 км → 16000 / 19200 (өдөр / шөнө) ✅

C хувилбарыг `gcc -Wall -Wextra main.c -o main` командаар хөрвүүлэхэд алдаа, анхааруулга гараагүй.
