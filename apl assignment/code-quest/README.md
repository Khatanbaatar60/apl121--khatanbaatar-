## Өөрийн тогтоосон дүрмүүд
1. **Тариф:** суух хөлс 1000₮, 1 км 1500₮, хүлээлгийн 1 минут 200₮, шөнийн нэмэгдэл 20%. Эдгээр нь жишээ утга бөгөөд кодын эхэнд `#define`-аар тодорхойлсон тул нэг газраас солиход болно.
2. **Үнийн томьёо:** `үнэ = суух + зай × км_үнэ + минут × мин_үнэ`. Шөнө бол нийт үнэ дээр 20% нэмнэ.
3. **Шөнө:** хэрэглэгч `1` (шөнө) эсвэл `0` (өдөр) гэж оруулна.
4. **Оролтын хязгаар:** зай > 0, хүлээлэг ≥ 0, шөнө нь зөвхөн 0 эсвэл 1. Буруу утга оруулбал "Буруу утга!" гэж мэдэгдээд дахин асууна (do-while). Зөвхөн тоо оруулна гэж үзсэн.
5. **Хүснэгт:** 1–10 км-ийн үнийг хүлээлэггүйгээр өдөр болон шөнөөр харуулна.
6. **Эрэмбэ:** хямдаас үнэтэй рүү. Аялал бүрийн хувьд өөрөөсөө хямд аялал хэд байгааг тоолж байрыг тогтооно. Ижил үнэтэй аялал ижил байр авна.
7. **Мөнгөн дүн:** C програм бүхэл төгрөгөөр (`%.0f`) хэвлэнэ.
